# icantswimm-web-project

## Project 2 - HTML Foundation Page

### Description

For project 2, I created a webpage showcasing my favorite video games of the last 3 years. I included a short description and a screenshot of each game, along with my ratings.

### What I Learned

While creating the page, I learned that HTML is much easier than I expected. I was able to put my ideas down in a way that is formatted pretty nicely without having to do much searching for syntax constantly.

### Challenges

As much as I liked the formatting of my website, I think it would have looked much better with a little bit of CSS. I also had some errors with W3C, but they were just semantic and easy to fix.
